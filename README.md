# Career Showcase Portfolio

A responsive personal portfolio website built with plain HTML5, CSS3, and vanilla JavaScript.

## Project Structure

- `index.html` – main portfolio page
- `style.css` – styling and responsive layout
- `script.js` – smooth scrolling, theme toggle, and form validation
- `assets/` – folder for images and other static assets

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://127.0.0.1:8000`.
